AgroMarket – Agricultural Marketplace

About

AgroMarket is a web-based agricultural marketplace that connects farmers with buyers. It allows users to browse agricultural products, view prices, check available quantities, and contact sellers.

Features

- Browse agricultural products.
- View product images, prices and descriptions.
- Search and filter products by category.
- View product locations and quantities.
- Contact sellers through WhatsApp.
- Responsive user interface.

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Structure

- "index.html" – Homepage
- "css/" – Stylesheets
- "js/" – JavaScript files
- "assets/images/" – Product images

How to Run

1. Download or clone the repository.
2. Extract the project folder if downloaded as ZIP.
3. Open the project in VS Code.
4. Run "index.html" using Live Server.

Note

This is a frontend demonstration project. Product listings use sample data and do not require a backend database.
